# Integration matrix

Superseded by **[integration-setup.md](integration-setup.md)**, which has the full per-provider table (credentials,
approvals, costs, implementation and test status, remaining work) and the setup procedure.

Summary (2026-10-18): **no integration has been tested against a real provider account.** First-party channels
(website chat, ADF intake, CSV import, Marketplace human-assisted intake) are fully exercised; Messenger, Twilio,
SMTP, IMAP, Google Calendar, Zoom, Google Places and Anthropic are implemented and tested with mocks/sandbox only;
Instagram, WhatsApp, Lead Ads and dealer-CRM APIs are not implemented; Facebook Marketplace chats have no API.
